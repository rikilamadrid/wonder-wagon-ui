# Motion

Mechanical, not bouncy. Things have detents, throws and travel. **Throw** is 180ms on
`cubic-bezier(.2,.7,.2,1)`; **settle** is `cubic-bezier(.4,0,.2,1)` for a lid heavier
than a lever; a **detent** counts in twelve steps. One reveal per screen at most.

<MotionSpecimen />

Every animation has a static equivalent. Under `prefers-reduced-motion` the tokens set
every duration to 1ms rather than `none`, so `transitionend` still fires for anything
that waits on it.
