# Object and quiet

The system's main defence against becoming either bland or cluttered, and it is not
advisory. **Object components** carry the brand: a hero object, the one signature
action, a well, a lever, loading/empty/error states, the case that holds an object.
**Quiet support components** — tables, forms, settings, logs, navigation, documentation
body, anything read for more than a minute — take Working sans, a quiet card, no
texture, no plates, no enamel beyond one accent rule.

<ObjectQuietSpecimen />

The test: if a component appears more than three times on one screen, it is quiet.
Objects are singular. The library ships physics and slots for objects, never the
objects; Pathfinder's atlascope and Forge's furnace stay in their products.
