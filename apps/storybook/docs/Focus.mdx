# Focus

A 3px ring at 3px offset, in an **environment-scoped** colour: ink on paper, pale in the
dark. One value cannot serve both — the pale ring measures 1.18:1 on Field Paper and is
simply not there. The ring sits on whatever is *behind* the control, so it follows the
panel, not the control.

A skeuomorphic control that loses focus visibility is broken, however it looks.
