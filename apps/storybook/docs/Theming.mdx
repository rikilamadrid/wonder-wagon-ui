# Theming

```
@wonder-wagon/tokens      the family: grounds, ink, hairlines, focus, depth, space, type
        ↓
shared semantics          ground · surface · ink · hairline · focus · well · status · accent · link · signal
        ↓
product theme             fills six slots + enamel + object radius + serial, inside @layer ww.theme
        ↓
product adapter / UI      React components here; regenerated CSS or a committed terminal module elsewhere
```

A theme **must** set `accent`, `accent-low`, `accent-ink`, `link`, `signal`,
`signal-edge`, its enamel day/night, and a four-value object radius. It **must not**
touch grounds, ink, hairlines, focus, depth or space — those are the family. The
contract is validated and every pairing measured on every build.

## Five reference themes, one composite

Same components, same layout. Only the six slots differ. Pathfinder is approved and
reproduces its shipped `--ww-*` block declaration for declaration; the bench, Forge
and Lorekeeper are pilots, Lorekeeper proven value for value against its own tokens; Lama is
a draft carrying only its Feature 02 values.
