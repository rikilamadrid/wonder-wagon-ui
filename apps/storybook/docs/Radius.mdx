# Radius

Quiet surfaces share one small set — because quiet surfaces *should* match. Objects
take an **asymmetric four-value set per product**, because a shared corner radius is
exactly how a family of distinct artifacts becomes four recoloured cards. The
irregularity is load-bearing.
